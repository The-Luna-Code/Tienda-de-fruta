# Tienda-de-fruta
Proyecto de tienda en Python para calcular totales y mostrar un descuento
Este programa está hecho en Python. Calcula el total de una compra de frutas y aplica un descuento del 10% cuando la compra supera los 100 soles

## Ejemplo de uso

Al ejecutar el programa, el usuario ingresa la cantidad de cada fruta que desea comprar:

Ingrese la cantidad de manzanas: 3.5
Ingrese la cantidad de bananas: 2
Ingrese la cantidad de naranjas: 1

El programa calcula el total de la compra y, si supera los 100 soles, aplica automáticamente un descuento del 10%.

Total de la compra: S/ 120.00
Total con descuento: S/ 108.00


# Agenda-telefonica

### Descripción: 
Este proyecto está desarrollado en Python y permite gestionar una agenda de contactos telefónicos. 
### Objetivo: 
Practicar programación en Python mediante la creación y gestión de un directorio de contactos.

## Ejemplo de uso 

Al ejecutar el programa, el usuario ingresa el nombre de la persona cuyo número de teléfono desea consultar:

Ingrese el nombre de la persona que desea buscar su número de teléfono: juan
El numero de telefono de Juan es: 123-456-7890

Si el nombre no está registrado en la agenda, el programa muestra un mensaje indicando que no se encuentra registrado:

Ingrese el nombre de la persona que desea buscar su número de teléfono: Melissa
Melissa no esta registrado en la agenda.
